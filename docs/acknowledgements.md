# Acknowledgements

CloudViPER builds upon the work of many individuals, organizations, and open source projects. We gratefully acknowledge their contributions to the digital preservation community.

## ViPER Project

CloudViPER is the web-based extension of [ViPER (Virtual Preservation Environment)](https://viper.openpreservation.org/), developed in collaboration with the Dutch Digital Heritage Network. ViPER's mission to reduce barriers to using and testing digital preservation software continues in CloudViPER's cloud-native architecture.

## Open Preservation Foundation

CloudViPER is developed and maintained by the [Open Preservation Foundation](https://openpreservation.org/), a not-for-profit organization committed to the long-term preservation of digital content through collaborative, practical approaches and shared solutions.

## Preservation Tools

CloudViPER integrates and provides access to industry-leading open source preservation tools:

- **[DROID](https://digital-preservation.github.io/droid/)** - File format identification tool by The National Archives UK
- **[JHOVE](https://jhove.openpreservation.org/)** - Format validation and characterization tool
- **[veraPDF](https://verapdf.org/)** - PDF/A validation tool
- **[MediaConch](https://mediaarea.net/MediaConch)** - Implementation checker for media files
- **[MediaInfo](https://mediaarea.net/en/MediaInfo)** - Technical metadata tool for audio and video files
- **[Tika](https://tika.apache.org/)** - Content detection and extraction framework by Apache
- **[HandBrake](https://handbrake.fr/)** - Video transcoding tool

## Technology Stack

CloudViPER is built with:

- **[Docker](https://www.docker.com/)** - Container platform
- **[Node.js](https://nodejs.org/)** - JavaScript runtime
- **[TypeScript](https://www.typescriptlang.org/)** - Type-safe development
- **[Express](https://expressjs.com/)** - Web application framework
- **[MySQL](https://www.mysql.com/)** - Database management
- **[Bootstrap](https://getbootstrap.com/)** - UI framework
- **[Traefik](https://traefik.io/)** - Reverse proxy and load balancer
