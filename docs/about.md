# About CloudViPER

CloudViPER is an open-source web-based interface for managing Docker containers, designed specifically for digital preservation workflows.

---

## Project Goals

The CloudViPER project aims to provide:

- A secure, user-friendly interface for container management
- Role-based access control for multi-user environments
- Comprehensive monitoring and logging capabilities
- Integration with digital preservation tools and workflows
- Open-source software that can be freely used and modified

---

## Open Preservation Foundation

CloudViPER is maintained by the [Open Preservation Foundation (OPF)](https://openpreservation.org), a non-profit organization dedicated to advancing digital preservation through open-source software and community collaboration.

### Our Mission

To provide expertise and support, empowering the digital preservation community to develop sustainable resources through open software and standards.

### Our Vision

A world where digital content is preserved and accessible for future generations through collaborative, practical approaches and shared solutions.

---

## Technology & Development

CloudViPER is built using modern web technologies and follows industry best practices:

- **TypeScript:** Type-safe code for improved reliability
- **Node.js & Express:** Fast, scalable web server
- **MySQL:** Robust data persistence
- **Docker:** Containerized deployment
- **Bootstrap:** Responsive, accessible UI
