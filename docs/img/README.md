# Images and Assets

Place your images and assets in this directory:

- `favicon.png` - Site favicon (32x32 or 64x64 pixels)
- `logo.png` - Site logo
- `opf-logo.png` - Open Preservation Foundation logo
- Screenshots and other images used in documentation

## Recommended Image Formats

- **Favicon:** PNG, 32x32 or 64x64 pixels
- **Logo:** PNG or SVG with transparent background
- **Screenshots:** PNG or JPG, optimized for web

## Image Optimization

Before adding images, optimize them for web:
- Use appropriate dimensions (no larger than necessary)
- Compress images to reduce file size
- Consider using WebP format for better compression

## Attribution

If using third-party images, ensure proper attribution and licensing.
