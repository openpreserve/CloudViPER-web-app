# CloudViPER

Manage your ViPER digital preservation toolkit from anywhere. Cloud-hosted or self-hosted, CloudViPER brings DROID, JHOVE, veraPDF, and more to your browser.

## Features

### Secure by Design
Built with security at its core, featuring authentication, authorization, and comprehensive audit logging.

### Container Management
Monitor and manage ViPER Docker containers with real-time status updates and resource tracking.

### Role-Based Access
Fine-grained access control with multiple user roles and permissions management.

### Resource Monitoring
Track CPU, memory, and disk usage with detailed metrics and historical data.

### MySQL Integration
Powered by MySQL for reliable data persistence and session management.

### REST API
Comprehensive API for programmatic access and integration with other tools.

---

## Built for Digital Preservation

CloudViPER extends the ViPER virtual machine concept to the cloud, providing web-based access to popular open source preservation tools including DROID, HandBrake, JHOVE, MediaConch, Mediainfo, Tika, and veraPDF.

Whether you're managing a single ViPER instance or orchestrating multiple preservation environments, CloudViPER provides secure access controls, comprehensive monitoring, and the flexibility to deploy anywhere.

## Quick Start

Get up and running with CloudViPER in minutes:

1. **Clone the repository:** Get the latest code from GitHub
2. **Configure environment:** Set up your environment variables and database
3. **Run with Docker Compose:** Launch all services with a single command
4. **Access the interface:** Open your browser and start managing your ViPER instances
